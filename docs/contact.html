Contribute to LADAL

Write a Tutorial

Do you have expertise in a method or tool that would benefit the LADAL community? We welcome contributions from researchers and practitioners at all career stages!

How to Submit a Tutorial

Step 1 Download the LADAL tutorial skeleton (.Rmd) — a template with the correct structure and formatting.

Step 2 Write your tutorial using the template. Include text, code, and examples following the LADAL style.

Step 3 Send your completed .Rmd file (along with any additional files needed to render it) to ladal@uq.edu.au.

Step 4 The LADAL team will review your submission. Once approved, your tutorial will be published as an official LADAL tutorial with full attribution.

We welcome tutorials on any topic relevant to language data science, corpus linguistics, text analytics, statistics, data visualization, or related areas.

Other Ways to Contribute

You don’t have to write a full tutorial to make a difference! Other ways to contribute include:

  • 🔧 Fix errors — help us improve existing tutorials (see below)
  • 📣 Share resources — point us to useful tools, datasets, or methods
  • 🎤 Present at a webinar — share your research or methods with the LADAL community
  • 🌐 Spread the word — share LADAL with colleagues, students, and networks
  • 🤝 Become an affiliate — join LADAL’s growing network of supporters (contact us to enquire)

Reporting and Fixing Errors

Found a mistake in a tutorial? We really appreciate you letting us know — every correction helps make LADAL better for everyone. Depending on how much time you have and how comfortable you are with GitHub, there are two ways to help.

Option 1: Report by Email

The simplest approach — just send us a message!

Contact
- LADAL team: ladal@uq.edu.au
- Martin Schweinberger: m.schweinberger@uq.edu.au

Please include
- The name or URL of the tutorial
- A brief description of the error
- (Optionally) your suggested correction

We will investigate and fix the issue as quickly as we can. We appreciate your patience — every report is acted on eventually!

Option 2: Fix Directly via GitHub ⭐ Recommended

The most efficient option! If you fix the error yourself via GitHub, we receive an automatic notification and can review and apply your correction quickly — no back-and-forth needed.

How to Fix a Bug on GitHub

What you need A free GitHub account (register here).

Steps

  1. Find the file — Navigate to the relevant tutorial file in the LADAL GitHub repository.

  2. Edit the file — Click the pencil ✏️ icon to edit the file directly in your browser. Make your correction.

  3. Submit a pull request — Scroll to the bottom of the page, add a short description of your change, and click “Propose changes”. This creates a pull request that the LADAL team can review.

  4. We review and merge — Once we approve your fix, it will be merged into the live tutorial — with credit to you!

We are working on a step-by-step tutorial to walk you through this process. In the meantime, GitHub’s own editing guide is a helpful starting point.
