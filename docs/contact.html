How to Submit a Tutorial

  1. 1

    Download the template

    Get the LADAL tutorial skeleton (.Rmd) — a template with the correct structure and formatting.

  2. 2

    Write your tutorial

    Use the template to write your tutorial. Include text, code, and examples following the LADAL style. Topics can cover language data science, corpus linguistics, text analytics, statistics, visualisation, or related areas.

  3. 3

    Send it to us

    Email your completed .Rmd file (along with any supporting files needed to render it) to ladal@uq.edu.au.

  4. 4

    Review and publication

    The LADAL team will review your submission. Once approved, your tutorial is published as an official LADAL tutorial with full attribution to you.

Reporting and Fixing Errors

Found a mistake in a tutorial? Every correction helps make LADAL better for everyone. Choose whichever option suits you best.

📧

Option 1 — Report by Email

The simplest approach. Send us a message with:

  • The name or URL of the tutorial
  • A brief description of the error
  • Your suggested correction (optional)

ladal@uq.edu.au
m.schweinberger@uq.edu.au

⭐

Option 2 — Fix via GitHub

Recommended

The most efficient option — fix it yourself and we receive an automatic notification to review and apply your change.

  • You need a free GitHub account
  • Find the file in the LADAL repository
  • Click the ✏️ pencil icon to edit in your browser
  • Submit a pull request with a short description
  • We review, merge, and credit you
