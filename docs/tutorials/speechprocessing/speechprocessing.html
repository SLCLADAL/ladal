What Is Speech Processing?

Speech processing refers to computational methods for analyzing spoken language.

Instead of starting with text, we begin with raw acoustic signals and extract:

  • Linguistic structure (words, segments)
  • Temporal alignment
  • Acoustic features (formants, pitch, intensity)
  • Speaker characteristics

Why Speech Processing Matters

Linguistic Applications

Research Area Application
Phonetics Measure vowel formants
Sociophonetics Compare speakers or groups
Prosody research Extract pitch and intensity
Corpus linguistics Align speech with transcripts
Forensic linguistics Speaker identification
Language acquisition Analyze pronunciation development

From Signal to Structure

Speech processing typically follows this pipeline:

Audio (.wav)
   ↓
Segmentation
   ↓
Automatic Speech Recognition

Forced Alignment
   ↓
Feature Extraction
   ↓
Statistical Analysis

4. Splitting Audio into Chunks

Segment long recordings into smaller units.

Code 
chunk_length <- 5  # seconds
samples_per_chunk <- chunk_length * wav@samp.rate

total_samples <- length(wav@left)
n_chunks <- ceiling(total_samples / samples_per_chunk)

chunks <- list()

for (i in 1:n_chunks) {
  start <- ((i - 1) * samples_per_chunk) + 1
  end <- min(i * samples_per_chunk, total_samples)
  chunks[[i]] <- extractWave(wav, from = start, to = end, xunit = "samples")
}

length(chunks)

Extract Time-Aligned Segments

Code 
segments <- result$segments

alignment_df <- data.frame(
  start = sapply(segments, function(x) x$start),

6. Forced Alignment

Forced alignment links words or phonemes to precise time stamps.

Options:

  • Montreal Forced Aligner (external tool)
  • Whisper segment timestamps (approximate alignment)

Alignment allows us to connect:

Text ↔︎ Time ↔︎ Acoustic Signal

7. Extracting Acoustic Features

Vowel Formants

Formants (F1, F2, F3) represent resonant frequencies of the vocal tract.

Code 
formants <- formant(wav, fmax = 5000, plot = FALSE)

formant_df <- data.frame(
  time = formants[,1],
  F1 = formants[,2],
  F2 = formants[,3]
)

head(formant_df)

8. Visualizing Vowel Space

Code 
ggplot(formant_df, aes(x = F2, y = F1)) +
  geom_point(alpha = 0.3) +
  scale_y_reverse() +
  scale_x_reverse() +
  labs(title = "Vowel Space (F1–F2)",
       x = "F2 (Hz)",
       y = "F1 (Hz)")

Reversing axes follows phonetic convention.

9. Linking Alignment and Acoustics

We can extract formants only during specific words.

Code 
first_segment <- alignment_df[1, ]

subset_formants <- formant_df %>%
  filter(time >= first_segment$start,
         time <= first_segment$end)

head(subset_formants)

This enables:

  • Word-specific acoustic analysis
  • Sociophonetic comparisons
  • Phoneme-level modeling
