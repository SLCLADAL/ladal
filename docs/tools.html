Tools

Interactive browser-based tools for text analysis — no installation required

LADAL tools are self-contained interactive tools that run entirely in your browser — no installation of R or any other software is required. Click a launch button on any tool card below, wait for the environment to load (typically 1–3 minutes on first launch), and start working with your own texts.

LADAL offers two types of tools, each suited to different access situations:

  • Shiny Tools — polished point-and-click applications. Require an Australian or New Zealand university login (AAF or Tuakiri). Launch via the ARDC BinderHub.
  • Jupyter Notebook Tools — flexible interactive notebooks. Available to everyone worldwide via MyBinder and GESIS — no login required.

Shiny Tools

What are Shiny tools? These are fully graphical, point-and-click applications built with R Shiny. You upload your texts, configure the analysis using menus and sliders, and download the results — no coding required at any step.

🔒 Access: All Shiny tools launch via the ARDC BinderHub, hosted by the Australian Research Data Commons on the NeCTAR Research Cloud. A university login via AAF (Australian Access Federation) or Tuakiri (New Zealand) is required. If you are outside Australia or New Zealand and need access, please contact Martin to discuss alternatives — the Jupyter Notebook tools below are available to everyone worldwide.
⚠ One server at a time: Each tool runs on its own server session, and you can only have one server running at a time. Before switching to a different tool, please stop your current server first:
  1. Go to binderhub.rc.nectar.org.au/hub/home
  2. Click Control Panel in the top navigation bar
  3. Click the red Stop My Server button
  4. Wait a few seconds until the button disappears, then launch your next tool

Text Preparation Tools

These tools help you prepare and pre-process your texts before analysis — cleaning, annotating, and organising your files.

✏️

FileRenamer

Batch rename plain-text files

Rename multiple plain-text files in bulk using find-and-replace patterns, numbering schemes, or prefix/suffix rules. Useful for standardising filenames before corpus analysis.

→ String Processing Tutorial
🚀 Launch via ARDC BinderHub
🔒 AU & NZ only Requires AAF or Tuakiri login
🧹

TextCleaner

Remove and replace text elements with regex

Remove XML/HTML tags, speaker labels, punctuation, numbers, URLs, and more from uploaded text files using pre-built options or custom regular expressions. Preview changes before applying to all files, then download cleaned texts individually or as a ZIP.

→ String Processing Tutorial
🚀 Launch via ARDC BinderHub
🔒 AU & NZ only Requires AAF or Tuakiri login
🏷️

POSTagger

Part-of-speech tagging & dependency parsing in 65+ languages

Tokenise, lemmatise, part-of-speech tag, and dependency-parse plain-text files using the UDPipe toolkit. Supports 65+ languages with pre-loaded models for the most common ones. Results download as a tidy table (Excel/CSV) or annotated text files (ZIP).

→ Tagging and Parsing Tutorial
🚀 Launch via ARDC BinderHub
🔒 AU & NZ only Requires AAF or Tuakiri login

Text Analysis Tools

These tools perform linguistic and statistical analysis on your texts — from concordancing and collocation to sentiment, topic modelling, and network visualisation.

🔍

Search for words or phrases across uploaded texts and generate KWIC (Keyword-in-Context) displays. Results can be sorted by left or right context and downloaded as Excel or CSV.

→ Concordancing Tutorial
🚀 Launch via ARDC BinderHub
🔒 AU & NZ only Requires AAF or Tuakiri login
🔑

KeywordExtractor

Keyness analysis vs. a reference corpus

Identify vocabulary that is statistically over- or under-represented in your texts compared to a reference corpus, using G², chi-squared, and log-ratio measures. Results download as Excel or CSV.

→ Keyness and Keyword Analysis Tutorial
🚀 Launch via ARDC BinderHub
🔒 AU & NZ only Requires AAF or Tuakiri login
🕸️

WordWebber

Word co-occurrence network visualisation

Build interactive and static word co-occurrence networks from uploaded texts. Enter a keyword to see which words appear most strongly nearby, scored by Mutual Information. Download networks as PNG and tables as Excel or CSV.

→ Network Analysis Tutorial
🚀 Launch via ARDC BinderHub
🔒 AU & NZ only Requires AAF or Tuakiri login
💬

SentimentExplorer

NRC word-emotion sentiment analysis

Score uploaded texts for positive/negative polarity and eight basic emotion categories (anger, fear, anticipation, trust, surprise, sadness, joy, disgust) using the NRC lexicon. Download results as Excel.

→ Sentiment Analysis Tutorial
🚀 Launch via ARDC BinderHub
🔒 AU & NZ only Requires AAF or Tuakiri login
🔗

CollocationCalculator

Collocation association measures

Calculate association measures (MI, t-score, log-likelihood, and more) to identify which words significantly collocate with a target word in your corpus. Download the full results table as Excel or CSV.

→ Collocation Analysis Tutorial
🚀 Launch via ARDC BinderHub
🔒 AU & NZ only Requires AAF or Tuakiri login
📊

TopicDetector

Unsupervised & seeded LDA topic modelling

Discover thematic structure across a text collection using Latent Dirichlet Allocation (LDA). Adjust the number of topics and terms interactively, explore topic-document distributions, and download results as Excel.

→ Topic Modelling Tutorial
🚀 Launch via ARDC BinderHub
🔒 AU & NZ only Requires AAF or Tuakiri login

Jupyter Notebook Tools

What are Jupyter Notebook tools? These are interactive R notebooks that run in a JupyterLab environment in your browser. They are slightly more code-visible than the Shiny tools but still require no local installation, and they are available to everyone worldwide — no university login needed.

🌐 Two open-access platforms — no login required:
  • MyBinder — a community-run open platform. Free for everyone. Startup typically takes 2–3 minutes.
  • GESIS BinderHub — hosted by the GESIS Leibniz Institute for the Social Sciences in Germany. Free for everyone and often faster than MyBinder. A good first choice if MyBinder is slow.
Both platforms are equivalent in functionality. If one is unresponsive, simply try the other.

Reporting Errors

🔧

Something not working?

If a tool fails to launch or behaves unexpectedly, please email Martin at m.schweinberger@uq.edu.au. When reporting an error, please include the tool name, which platform you used (ARDC, MyBinder, or GESIS), and a brief description of what happened. We will investigate and resolve issues as quickly as we can — thank you for letting us know.
