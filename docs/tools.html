Tools

Interactive browser-based tools for text analysis — no installation required

LADAL tools are self-contained Shiny applications that run in your browser — no installation of R or any other software is required. Simply click a launch button below, wait for the environment to load (typically 1–2 minutes on first launch), and start working with your own texts.

⭐ Recommended

ARDC BinderHub

Hosted by the Australian Research Data Commons. More generous computing resources and faster load times. Requires authentication through an Australian or New Zealand research organisation covered by the AAF or Tuakiri.

Open access

mybinder.org

Free and open — no account or institutional login required. Suitable for users outside Australia/New Zealand or without AAF/Tuakiri access. May have lower resource limits and slower load times.

Reporting Errors

🔧

Something not working?

If a tool fails to launch or behaves unexpectedly, please email Martin at m.schweinberger@uq.edu.au. When reporting an error, please include the tool name, which launch option you used (ARDC BinderHub or mybinder.org), and a brief description of what happened. We will investigate and resolve issues as quickly as we can — thank you for letting us know.
