TOOLS

Author

Created by LADAL contributors

Overview

This page lists the interactive tools provided by LADAL. Each tool is a self-contained Jupyter notebook that runs in your browser — no installation of R or any other software is required. To launch a tool, click the badge or the linked tool name.

Two Launch Options

Two launch links are provided for every tool:

  • ARDC BinderHub — hosted by the Australian Research Data Commons. Offers more generous computing resources and is the recommended option if you have access. Requires authentication through an Australian or New Zealand research organisation covered by the Australian Access Federation (AAF) or Tuakiri.
  • mybinder.org — free and open, no account required. Suitable for users outside Australia/New Zealand or those without AAF/Tuakiri access.

Tools may take up to a few minutes to launch while the computing environment is prepared. This is normal — please be patient.

Tools

Concordancing

The Concordancing Tool allows you to create Keyword-in-Context (KWIC) displays of words or phrases in a single text or collection of texts, and to download the resulting table. This allows you to examine how your chosen words or phrases are used in context across the texts you provide.

To learn more about concordancing and how to interpret KWIC displays, see the Concordancing tutorial.

Launch Concordancing Tool on ARDC BinderHub (Requires Authentication)

Launch Concordancing Tool on mybinder.org (No Authentication Necessary)

Collocations

The Collocation Tool calculates various association measures (collocation statistics) based on textual input and allows you to download the resulting table. These association measures allow you to examine which words are statistically more likely to occur near each other in your texts.

To learn more about collocations and association measures, see the Collocation and N-gram Analysis tutorial.

Launch Collocation Tool on ARDC BinderHub (Requires Authentication)

Launch Collocation Tool on mybinder.org (No Authentication Necessary)

Keywords

The Keyword Tool calculates various keyness measures describing how words are over- or under-represented in the texts you provide, compared to your chosen reference corpus. This is useful for identifying the vocabulary that is distinctive to a particular text, author, genre, or time period.

To learn more about keyness analysis, see the Keyness and Keyword Analysis tutorial.

Launch Keyword Tool on ARDC BinderHub (Requires Authentication)

Launch Keyword Tool on mybinder.org (No Authentication Necessary)

Part-of-Speech Tagging

The POS-Tagging Tool allows you to computationally add part-of-speech tags to texts or collections of texts in more than 60 languages, and to download the resulting tagged texts. POS tagging can be used to identify only the nouns used across a collection of texts, to disambiguate words that can function as more than one word class (e.g. words that can be both a noun and a verb), or as a pre-processing step for more advanced grammatical analysis.

To learn more about POS tagging and its applications, see the Analysing Learner Language tutorial.

Launch POS-Tagging Tool on ARDC BinderHub (Requires Authentication)

Launch POS-Tagging Tool on mybinder.org (No Authentication Necessary)

Corpus Text Cleaning

The Corpus Cleaning Tool allows you to remove and replace words, tags, and other elements from the text data you upload, and to download the cleaned texts. This allows you to quickly strip repetitive structures — such as XML or HTML markup, speaker labels, headers, or boilerplate text — that might otherwise distort the results of a subsequent analysis.

To learn more about text cleaning and string processing, see the String Processing tutorial.

Launch Corpus Cleaning Tool on ARDC BinderHub (Requires Authentication)

Launch Corpus Cleaning Tool on mybinder.org (No Authentication Necessary)

Network Analysis

The Network Analysis Tool allows you to generate and download network graphs based on your data. Unlike the other tools, this tool requires structured data describing the edges (connections) and their weights in your network, rather than a collection of plain texts. Network analysis can be used to visualise and quantify relationships between words, characters, authors, speakers, or any other entities that can be meaningfully connected.

To learn more about network analysis, see the Network Analysis tutorial.

Launch Network Analysis Tool on ARDC BinderHub (Requires Authentication)

Launch Network Analysis Tool on mybinder.org (No Authentication Necessary)

Topic Modelling

The Topic Modelling Tool allows you to generate custom topic models using unsupervised and supervised LDA (Latent Dirichlet Allocation) and to download the results as an MS Excel spreadsheet. Topic modelling supports distant reading approaches, allowing you to explore the thematic content of a large collection of texts without needing to read every document individually.

To learn more about topic modelling, see the Topic Modelling tutorial.

Launch Topic Modelling Tool on ARDC BinderHub (Requires Authentication)

Launch Topic Modelling Tool on mybinder.org (No Authentication Necessary)

Sentiment Analysis

The Sentiment Analysis Tool allows you to perform a sentiment analysis on your texts and download the results as an MS Excel spreadsheet. The tool uses a word-level sentiment scoring approach to estimate whether texts lean positive (“This sandwich is great!”) or negative (“The worst sandwich I’ve ever been served”). It can also be used to examine eight basic emotional associations — anger, fear, anticipation, trust, surprise, sadness, joy, and disgust — of the words in your texts.

To learn more about sentiment analysis, see the Sentiment Analysis tutorial.

Launch Sentiment Analysis Tool on ARDC BinderHub (Requires Authentication)

Launch Sentiment Analysis Tool on mybinder.org (No Authentication Necessary)

Reporting Errors

If a tool is not working as expected or fails to launch, please contact Martin at m.schweinberger@uq.edu.au. When reporting an error, it is helpful to include the name of the tool, which launch option you used (ARDC BinderHub or mybinder.org), and a brief description of what happened. We will investigate and resolve issues as quickly as we can — thank you for bringing them to our attention.
